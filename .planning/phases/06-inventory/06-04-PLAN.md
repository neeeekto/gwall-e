<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→usecase (форма Phase 7) | actor приходит снаружи (в Phase 7 — из gRPC-interceptor); usecase атрибутирует событие, не доверяет агрегату |
| usecase→outbox | события должны попасть в outbox в той же tx-форме, что repo.Save (atomicity) |
| usecase→uniqueness query-порт | FQDN-конфликт пересекает границу чтения-хранилища; результат — доменный конфликт, не DB-ошибка |

> Чистый домен на фейках: tx — фейк (зовёт fn). Реальная atomicity (panic между Save и Append) — Phase 7. Форма зафиксирована сейчас (Pitfall 8).
