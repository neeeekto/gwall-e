# Агенты (`agents/`)

Автономные агенты, разворачиваемые на хостах для сбора информации и выполнения операций. На текущий момент — заглушки.

| Путь | Назначение | Статус |
|------|------------|--------|
| `agents/informator/` | Агент сбора информации о хостах (предположительно — судя по имени) | Заглушка, пустой (кода нет) |
| `agents/skytor/` | Агент для BitTorrent протокла на хостах | Заглушка, пустой |

> Назначение выведено из имён модулей, а не зафиксированный контракт. Уточняй по мере появления кода.
