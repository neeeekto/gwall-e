# Тесты

## Фреймворк

- Тесты пишутся на **Ginkgo** (BDD-структура: `Describe`/`Context`/`It`) + **Gomega** (матчеры: `Expect(...).To(...)`).
- Это распространяется на новый тестовый код. Существующие тесты на стандартном `testing` не переписываются массово без отдельной задачи.

## Язык комментариев

- **Комментарии в тестах — на английском.**
- Это исключение из общего правила проекта (доменный код и его комментарии — на русском, см. `CLAUDE.md`). В тестах — английский.
- Описания спецификаций (строки в `Describe`/`Context`/`It`) — тоже на английском, чтобы вывод Ginkgo читался единообразно.

## Пример

```go
var _ = Describe("HostRegistry", func() {
    // happy path: a new host is stored and retrievable
    It("registers a new host", func() {
        Expect(registry.Register(host)).To(Succeed())
    })
})
```

## Как писать

Эти правила — источник истины. Процедура написания тестов (найти код под тест → suite-файл → спеки → прогон правильной командой) вынесена в скилу `/write-tests`. Контент скилы лежит инструмент-нейтрально в [`.ai/skills/write-tests/`](../.ai/skills/write-tests/SKILL.md); Claude Code видит её через симлинк `.claude/skills/write-tests`. Скила ссылается на этот файл и не дублирует правила.
