# Memory Bank

Командный, версионируемый банк знаний проекта **gwall-e**. В отличие от личной памяти агента (она хранится вне репозитория, в `~/.claude`), этот банк **коммитится в git** и обязателен к соблюдению всеми — людьми и AI-агентами.

Агент (Claude Code) обязан читать этот банк в начале работы и следовать правилам отсюда. Указатель на банк добавлен в корневой `CLAUDE.md`.

## Содержание

| Файл | О чём |
|------|-------|
| [structure.md](structure.md) | Структура проекта: раскладка репозитория, workspace |
| [libraries.md](libraries.md) | Общие библиотеки `pkg/` |
| [agents.md](agents.md) | Агенты `agents/` |
| [testing.md](testing.md) | Конвенции написания тестов |

## Как пополнять

- Один файл — одна тема (тесты, логирование, стиль API и т.п.).
- Пиши конкретные, проверяемые правила, а не общие слова.
- Добавил файл — впиши строку в таблицу выше.
