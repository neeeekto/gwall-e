# .ai — инструмент-нейтральные ассеты для AI-агентов

Чтобы не завязываться на один инструмент, контент агентских ассетов (скилы и т.п.)
хранится здесь как обычный markdown. Любой агент/инструмент может читать эти файлы напрямую.

Конкретные инструменты подключают их у себя ссылками, не копируя:

| Инструмент | Как подключено |
|------------|----------------|
| Claude Code | `.claude/skills/<name>` → симлинк на `.ai/skills/<name>` (скила находится нативно, `/<name>`) |

## Содержание

- `skills/` — процедуры («как сделать задачу»). Правила-источник-истины живут в [`memory-bank/`](../memory-bank/README.md); скилы на них **ссылаются**, а не дублируют.

## Добавить скилу

1. Создай `skills/<name>/SKILL.md` (frontmatter `name`/`description`/`trigger` — формат Claude Code, но тело — обычный markdown, читаемый любым инструментом).
2. Подключи в нужный инструмент ссылкой. Для Claude Code:
   ```bash
   ln -s ../../.ai/skills/<name> .claude/skills/<name>
   ```
